# Code of conduct

Be precise, be kind, argue about kernel parameters not about people.

In practice:

- Disagreements about detection quality are settled with a config sample and
  a `sysctl -a` trace, not with volume.
- No harassment, no personal attacks, no gatekeeping. Beginners asking
  "why does accept_redirects matter?" deserve the same patience as kernel
  developers.
- Keep security reports private until a fix ships (see SECURITY.md).

Maintainers who do not hold this line lose maintainer status.
